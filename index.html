資料管理（備份／還原）

匯出的備份不包含 Gemini API Key。歷史新聞保存在此瀏覽器的 IndexedDB；清除網站資料或更換瀏覽器前，建議先匯出備份。

新聞候選資料由本站的 Vercel /api/news 中繼服務取得；它會依次嘗試多個公開新聞來源並自動 fallback。Gemini 只用來篩選、翻譯標題及根據提供的標題／來源資料做保守整理，不使用 Google Search grounding。每日自動更新的意思是：當此頁在新的一天首次被打開（或重新回到前景）而當天尚無目前主題的日報，就自動補生成一次；瀏覽器完全關閉時不會在背景執行。
